# Step 4 METAR visual proof

This fixture-only executable creates deterministic Windows PNG evidence from
the production brain projection, accessory layout, wrapping, rail, drawer, and
main-card raster paths. It performs no network access and is never linked into
the normal plugin.

Run the Release executable with one output-directory argument. It writes 43
approved images plus timing, publication, and SHA-256 manifests. The accessory
input boundary set includes truthful ATIS/PDC empty drawers, METAR/ATIS/PDC
switch outcomes, active close, double-click final state, rapid-alternation
final state, and clean re-enable state. Repeated PNG rendering must have zero
pixel differences.
